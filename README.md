# React + Supabase To-Do App

A responsive single-page task manager built with **React**, **Vite**, and **Supabase**. It started as a simple to-do list and was extended feature by feature to demonstrate product development, React state management, database updates, filtering, theming, and drag-and-drop ordering.

## Features

- Add a task
- Mark a task complete or incomplete
- Delete a task
- Edit a task title and save or cancel the edit
- Filter tasks: **All**, **Active**, and **Completed**
- Search tasks by title
- Add an optional due date
- Set a priority: **Low**, **Medium**, or **High**
- Assign a category: **Work**, **Personal**, **Study**, or **Shopping**
- Show completion date and time for completed tasks
- Toggle between light mode and dark mode
- Display priority and category as color-coded labels
- Drag tasks by the `⠿` handle to arrange them manually
- Save the manual task order in Supabase

## Tech Stack

## Project Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

### 2. Install packages

```bash
npm install
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

### 3. Add Supabase environment variables

Create a file named `.env.local` in the project root:

```env
VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

Find both values in **Supabase Dashboard → Project Settings → API**.

### 4. Start the app

```bash
npm run dev
```

Open the local URL shown in the terminal, usually `http://localhost:5173`.

## Supabase Database

The application uses one table named `tasks`.

| Column | Type | Purpose |
| --- | --- | --- |
| `id` | `bigint` | Unique task ID |
| `title` | `text` | Task name |
| `completed` | `boolean` | Whether the task is complete |
| `created_at` | `timestamptz` | When the task was created |
| `due_date` | `date` | Optional task deadline |
| `priority` | `text` | `low`, `medium`, or `high` |
| `category` | `text` | `work`, `personal`, `study`, or `shopping` |
| `completed_at` | `timestamptz` | When the task was marked complete |
| `position` | `int4` | Manual drag-and-drop order |

### Create the table

Run this in **Supabase Dashboard → SQL Editor → New query**:

```sql
create table if not exists public.tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  completed boolean not null default false,
  created_at timestamptz not null default now(),
  due_date date,
  priority text not null default 'medium',
  category text not null default 'personal',
  completed_at timestamptz,
  position int4 not null default 0,
  constraint tasks_priority_check check (priority in ('low', 'medium', 'high')),
  constraint tasks_category_check check (category in ('work', 'personal', 'study', 'shopping'))
);
```

If the original table already exists, add only the missing columns through the Table Editor or with `alter table` statements.

> For a demo without authentication, configure the appropriate Supabase Row Level Security policies for `select`, `insert`, `update`, and `delete`. For production, add Supabase Auth and restrict every task to its owner.

## How Each Feature Works

### Add, complete, and delete tasks

The React app inserts new rows into Supabase, updates `completed` when the checkbox is clicked, and deletes a row by its `id`.

### Edit task

When **Edit** is clicked, React stores:

- `editingTaskId` — the task currently being edited
- `editTitle` — the temporary typed title

Clicking **Save** updates `title` in Supabase. Clicking **Cancel** discards the temporary text.

### Filter and search

Filtering is done in React without a database change:

- **All**: shows every task
- **Active**: shows tasks where `completed` is `false`
- **Completed**: shows tasks where `completed` is `true`

Search compares the typed value with each task title, ignoring uppercase/lowercase differences.

### Due date

The add-task form includes an HTML date input. Its value is saved as `due_date`. If no date is chosen, Supabase stores `NULL`.

### Priority and category

The add-task form provides dropdowns for priority and category. The UI displays them as colored labels:

- Low priority: green
- Medium priority: yellow
- High priority: red
- Work, Personal, Study, and Shopping: different category colors

### Completed-task history

When a task is completed, the app saves the current timestamp:

```js
completed_at: task.completed ? null : new Date().toISOString()
```

If the task is marked incomplete again, `completed_at` is cleared.

### Dark mode

The `darkMode` React state controls a `dark-mode` CSS class on the page. The same toggle button switches between light and dark colors.

### Default name order and manual drag-and-drop order

Tasks initially load in alphabetical order by title. The `position` field preserves any custom ordering created by dragging a task with its `⠿` handle.

After a task is dropped, every task receives an updated numeric `position` and that order is saved to Supabase. The user’s manual arrangement takes priority over the default alphabetical order.
